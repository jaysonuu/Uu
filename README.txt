RESTAURANT P&L APP  /  餐厅损益应用

1. Icon (optional)  图标：open make-icon.html in a browser, add your logo or letters, download the 4 PNG files, replace the ones in this folder.
   用浏览器打开 make-icon.html，放入你的标志或文字，下载 4 个 PNG 文件，替换本文件夹里的同名文件。
2. Host  上传：upload ALL files in this folder to an https host (Netlify Drop, Cloudflare Pages, GitHub Pages).
   把本文件夹所有文件上传到支持 https 的免费托管服务。
3. Install  安装：open the address on your phone once while online. iPhone Safari: Share > Add to Home Screen. Android Chrome: menu > Install app.
   联网时在手机上打开一次。iPhone：Safari 分享 > 添加到主屏幕。安卓：Chrome 菜单 > 安装应用。
4. Offline  离线：after the first online visit it opens without internet. Data is stored on that phone only.
   首次联网访问后即可离线使用。数据只保存在该手机上。
After you change files and re-upload, close and reopen the app twice to load the update.
更新文件重新上传后，请把应用关闭再打开两次以加载新版本。
